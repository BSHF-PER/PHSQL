## 📖 About The Project

**PHSQL** is a modern, lightweight, and highly intuitive web-based database management tool designed to be the ultimate alternative to phpMyAdmin. 

Traditional database managers are often cluttered, outdated, and require a steep learning curve. PHSQL bridges this gap by offering a **visual, drag-and-drop experience** that minimizes the effort required to design schemas, write queries, and manage data. Whether you are a beginner learning database concepts or a seasoned developer prototyping quickly, PHSQL provides a seamless, beautiful, and efficient workflow.

---

## ✨ Key Features

- 🎨 **Visual Table Designer**: Create and modify tables effortlessly with an intuitive drag-and-drop interface for managing Foreign Keys (FKs) and relationships.
- 🗺️ **Live Interactive ERD**: Visualize your entire database schema with a dynamic Entity-Relationship Diagram featuring infinite zoom and pan capabilities.
- ✏️ **Inline Data Editing**: Modify records directly within the data grid without navigating through cumbersome, multi-step forms.
- 💻 **Advanced SQL Editor**: A built-in, syntax-highlighted SQL console for writing, executing, and analyzing complex queries in real-time.
- ⚡ **Built-in Migration Support**: Automatically generate schema migration scripts to version-control your database changes effortlessly.
- 🌗 **Modern UI/UX**: A fully responsive, clean interface with native Dark/Light mode support, designed for long coding sessions.

## 🛠️ Installation & Setup

Getting started with PHSQL is incredibly simple. No complex composer dependencies or Node.js build steps are required. Follow these straightforward steps:

### Prerequisites
- A local server environment like **XAMPP**, **WAMP**, **MAMP**, or **LAMP**.
- PHP `8.0` or higher.
- MySQL or MariaDB running on your server.

### Step-by-Step Guide

1. **Clone or Download the Repository**
   ```bash
   git clone https://github.com/BSHF-PER/PHSQL.git
   cd PHSQL
   ```

2. **Move Files to Your Server Directory**
   Locate the `www` folder inside the cloned repository. Copy **its contents** (not the folder itself) into your local server's root directory:
   - **XAMPP (Windows)**: `C:\xampp\htdocs\PHSQL`
   - **WAMP (Windows)**: `C:\wamp64\www\PHSQL`
   - **MAMP (macOS)**: `/Applications/MAMP/htdocs/PHSQL`
   - **LAMP (Linux)**: `/var/www/html/PHSQL`

3. **Start Your Local Server**
   Open your XAMPP/WAMP control panel and ensure both **Apache** and **MySQL** services are running.

4. **Launch PHSQL**
   Open your favorite web browser and navigate to:
   ```
   http://localhost/PHSQL
   ```

5. **Connect to Your Database**
   Enter your MySQL/MariaDB credentials (Host, Username, Password) on the welcome screen, and you are ready to manage your databases visually!
